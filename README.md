# Fare-Ride Customer Web App

This is the customer/passenger front-end starter for Fare-Ride.

Files:
- index.html
- style.css
- app.js

## GitHub Pages
1. Create a GitHub repository.
2. Upload these 3 files to the repository root.
3. Open Settings > Pages.
4. Under Build and deployment, choose "Deploy from a branch".
5. Select the `main` branch and `/ (root)`.
6. Save.

This version is a front-end prototype. Real maps, user accounts, payments, live driver tracking,
Firebase/backend data, and real fare calculations can be connected next.
